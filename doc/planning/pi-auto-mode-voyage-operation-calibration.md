# Same-data operation-conditioned calibration comparison

## Outcome and practical recommendation

Do not adopt the tested full independent operation split as a demonstrated upgrade.
It improved Brier on the shared held-out rows,
but worsened log loss,
made a wrong resolution at 80/20 where the pooled control abstained,
and did not pass any operation-by-operation test gate.
Neither candidate passed a declared validation gate.
The pooled candidate remains a research control,
not a production recommendation.

The new bank also contains opposite references with identical inputs inside the same operation.
Routing alone therefore does not repair all information loss in these two coordinates.
Further refitting or threshold adjustment on unchanged inputs cannot distinguish those collided rows.
Resolving those particular collisions requires additional discriminative evidence,
not more splitting or refitting of unchanged inputs.
Other calibrators may still change behavior on distinguishable rows;
this study does not rule out useful selective coverage with abstention.
No further phase or production change is selected by this result.

## Compared estimators

The pooled control keeps four source-kind/axiom heads.
The operation-conditioned candidate uses twelve source-kind/axiom/operation heads.
Code routes each row from its verified operation projection;
unknown operations are rejected,
never mapped to a fallback.
Both variants consume exactly the same source/axiom observations and raw feature pairs.
Each head still receives only its own margin and level as numeric coordinates.
No case,
resource,
source-text,
or operation identifier is a numeric feature.

Both use the byte-identical first-party numerical solver,
fit-only population standardization,
summed binary log loss plus unit L2 slope penalty,
and an unpenalized intercept.
The conditioned model changes parameter count,
head-specific normalization,
and per-head sample count.
The same summed-loss penalty also has different per-row strength.
The comparison therefore measures the specified estimator designs,
not a pure causal effect of the operation label alone.
