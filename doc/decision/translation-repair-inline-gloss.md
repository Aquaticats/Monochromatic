# Terms with no English equivalent get an inline gloss on first use

Decided by the owner on 2026-09-03 ("Inline gloss on first use"),
asked with three options after the
XIEPT2 reading raised 大证 and WER.

## The rule

- A term the ORIGINAL uses that has no English equivalent (a community term,
  an institution,
  an
  abbreviation local to the person's world) is kept and glossed in the same sentence the first time it
  appears:
  the term,
  then a short explanation in parentheses or a following clause.
  Later uses carry the
  term alone.
- Not footnotes:
  the site's rendering of markdown footnotes is unverified,
  and a footnote convention
  would be one more thing the house policy has to teach every role.
- Not per case:
  a page must explain the same term the same way,
  and judges need one rule to check.

## Rejected alternatives

- Footnotes:
  clean sentences,
  unverified rendering,
  a new convention.
- Translator decides per case:
  fits each passage,
  inconsistent across a page and across entries.
