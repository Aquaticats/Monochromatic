File manager sticky flow: live companion

Interactive companion to file-manager-sticky-flow.md (the full audit; this page only demonstrates). The demo below is the shipped architecture at miniature scale: one overflow: auto scroller, each column a normal-flow stack of rail wrappers, each pane position: sticky; top: 0 inside its rail. No script positions anything while you scroll.

Live demo

Scroll the pane strip vertically. The root pane (blue border) pins to the top and rides the scroll while any of its direct children is on screen, then releases at its rail's end; every pane with children does the same inside its own rail. The readout mirrors the two facts the real boundary tests assert: rootPinned and overlapCount.

The grid, drawn to scale

Columns are lineage depth; rows come from the tidy tree (parent aligns with first child, a later sibling starts below the previous sibling's whole subtree).

One pane's band

A band spans from the pane's own row to its deepest direct child's bottom edge. Leaves get a band exactly their own size (zero travel).

Release point: original vs sticky

For a band 2116px tall in a 600px viewport: the original stops following when the band's bottom reaches the viewport bottom (scroll 1516); sticky follows until the pane itself hits the band's end (scroll 1596). Sticky's release point does not depend on viewport height.
