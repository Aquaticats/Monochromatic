# config-tsdown

Ready to publish.

Shared [tsdown](https://tsdown.dev/) build configurations for Monochromatic packages.

## Configurations

Five platform-specific presets are available:

- **Neutral** (default): browser-compatible builds targeting resolved browser entries from root Browserslist
- **Neutral unbundled DTS**: neutral builds that use rolldown's builtin `isolatedDeclarationPlugin`
- **Node**: server-side builds with `platform: 'node'` and resolved Node entries from root Browserslist
- **Node unbundled DTS**: Node builds that use rolldown's builtin `isolatedDeclarationPlugin`
- **Client**: browser bundles for `<script type="module">` tags, no `.d.ts` output

All presets load `.browserslistrc.resolved.local.json`, generated by `mise run sync:files`.
If that local generated file is absent, they dynamically import `browserslist` and resolve
`.browserslistrc` at build time. Browser presets filter out Node entries, and the Node preset
filters out browser entries before converting Browserslist names to tsdown targets. They also bundle
workspace dependencies (`@monochromatic-dev/*`) into the output so built artifacts are self-contained
outside the monorepo.

## DTS bundling policy

Use bundled DTS for published library packages and any package whose public API is its exported TypeScript types.
The default Neutral and Node presets set `dts: true`, which lets tsdown run `rolldown-plugin-dts` and emit a single
bundled declaration entry such as `index.d.mts`. This stays appropriate for `packages/module/*`, parser packages,
and build-tool packages that consumers import as libraries.

Use unbundled DTS for private applications, CLIs, Pi extensions, Claude Code plugins, and other executable packages
that expose types only for local workspace consumers or host integration metadata. The unbundled presets disable
`rolldown-plugin-dts` and add rolldown's builtin `isolatedDeclarationPlugin`, which emits one `.d.ts` asset per source
module and skips the declaration rebundling pass. Packages using these presets must include `dist/final` in `files`
and point any `exports["."].types` entry at the emitted entry `.d.ts` file, often under a mirrored `src/` path.

Use the Client preset for browser scripts loaded by HTML pages. It sets `dts: false` because these bundles are consumed
as runtime assets, not as TypeScript libraries.

Do not use unbundled DTS for published libraries unless the package intentionally ships its internal declaration graph.
Consumers must receive every emitted `.d.ts` file referenced by the entry declaration.

## File naming convention

Per-package configs are named `tsdown.<platform>.config.ts`, never bare `tsdown.config.ts`. The platform infix matches
`build:js:<platform>` mise task template at the monorepo root, which invokes
`tsdown --config tsdown.<platform>.config.ts` directly. A bare-named config will not be picked up by any task.

- `tsdown.browser.config.ts` for the neutral preset (browser-compatible, uses Browserslist targets)
- `tsdown.node.config.ts` for the Node preset (uses Browserslist targets)
- `tsdown.client.config.ts` for the client preset

A package adds whichever subset of the presets it actually builds, then mirrors them in its `mise.toml` by extending
the matching `build:js:<platform>` templates. Packages that build for multiple platforms keep one config file per
platform; there is no combined config.

## Usage

```ts
// tsdown.browser.config.ts -- neutral build
import base from '@monochromatic-dev/config-tsdown/.ts';
import { defineConfig, } from 'tsdown';
export default defineConfig({ ...base, entry: ['./src/index.ts',], },);
```

```ts
// tsdown.browser.config.ts -- neutral build with unbundled DTS
import base from '@monochromatic-dev/config-tsdown/.unbundled-dts.ts';
import { defineConfig, } from 'tsdown';
export default defineConfig({ ...base, entry: ['./src/index.ts',], },);
```

```ts
// tsdown.node.config.ts -- Node.js build
import base from '@monochromatic-dev/config-tsdown/.node.ts';
import { defineConfig, } from 'tsdown';
export default defineConfig({ ...base, entry: ['./src/index.ts',], },);
```

```ts
// tsdown.node.config.ts -- Node.js build with unbundled DTS
import base from '@monochromatic-dev/config-tsdown/.node.unbundled-dts.ts';
import { defineConfig, } from 'tsdown';
export default defineConfig({ ...base, entry: ['./src/index.ts',], },);
```

```ts
// tsdown.client.config.ts -- browser client bundle
import base from '@monochromatic-dev/config-tsdown/.client.ts';
import { defineConfig, } from 'tsdown';
export default defineConfig({ ...base, entry: ['./src/client.ts',], },);
```

## Output directories

- Neutral: `dist/final/neutral/`
- Node: `dist/final/node/`
- Client: `dist/client/`
