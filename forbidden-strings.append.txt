# Rules banning a bare identifier must be written so the pattern does not match
# its own text, because this scanner has no per-rule path scoping and no per-rule
# allowlists (package/forbidden-strings/cli/README.md, "When to pick something
# else"), so it reads this appendix as ordinary content like any other file. A
# literal rule body therefore matches itself, and every later edit to this file
# fails the commit on a line nobody touched. Bracketing one character keeps the
# matched text identical while breaking the self-match.

==> crn-renamed-inert-collection-member <==
# Renamed to the member-channel authority in prefer-readonly-parameter-type.
# "Inert" claimed these default-library members ran no user code, which an
# accessor-bearing receiver disproved for every Array entry: at, includes,
# indexOf, lastIndexOf, toReversed, toSpliced, pop and copyWithin all invoke an
# indexed getter, and that getter can restructure the receiver. The word invites
# a future reader to re-derive the false claim, so the concept is now a named
# channel per member. Evidence:
# doc/decision/prefer-readonly-member-channel-authority.md.
/(?:INERT_MEMBERS_BY_INTERFAC[E])|(?:isInertCollectionMembe[r])|(?:isInertDefaultLibraryMembe[r])|(?:effect-inert-member-authorit[y])/

==> crn-renamed-deferred-iterator-member <==
# Renamed to ITERATOR_MEMBER_NAMES in prefer-readonly-parameter-type. "Deferred"
# claimed nothing in the model separated creating an iterator from consuming one,
# so keys, values and entries stayed out of the member-channel authority. Nothing
# needed to separate them: receiverClaimAnswerable consults the authority while
# inspecting the creating call, and for-of and spread advance an iterator through
# no CallExpression, so a creation-only fact had no consumer. The entries now
# claim the union of both operations. The old name invites a future reader to
# re-derive a deferral that was never load-bearing. Evidence:
# doc/decision/prefer-readonly-member-channel-authority.md.
/DEFERRED_MEMBER_NAME[S]/
