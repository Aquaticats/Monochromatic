# The git wrapper's folders that use each other today, one line per use.
# What: the uses of a loop that the allow list of rust/folder-uses-links tolerates until a round untangles them.
# Why: the crate switched the layout rules on with the loops it has on 2026-11-25
#      (doc/decision/cli-git-layout-rules-on-with-a-shrinking-allow-list.md).
# How: a line is `uses <folder> -> <folder>`, paths relative to package/git-policy/cli.
#      A line matches only while the use is still made and its two folders are still in one loop.
#      A line that matches nothing is a finding, so a round that untangles a use deletes its line.
