Read the status, not just the row count

  • Empty query: no lookup has failed; a prompt is not a no-match verdict.
  • Completed query with no matches: the current query and source must have been fully evaluated. The zzq fixture illustrates wording/fit only, not a real evaluation.
  • Known source failure: only a verified inability to search the current source can justify an unavailable message. A still-visible browser and playing deck make the broad fixture phrase “Library unavailable” especially misleading. No automatic recovery is established.
  • Other conditions: confirmed empty searchable inventory, incomplete enumeration and analysis progress are distinct. A zero-length track list does not prove that no folder names can match.
