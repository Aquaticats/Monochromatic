Historical alternatives and rankings

Entry edit focus

When Search opens

Ranking: E-fast > E-tap. A Search action usually starts with typing; E-tap gives an unobstructed initial view at the cost of another action. These E labels do not rename the accepted E2 crease decision.

Visible Back arrow

When a keyboard is shown

Ranking: A-exit > A-hide. D47 requires a Back path, not its first action during typing. A-exit gives that page control one stable exit meaning; A-hide adds a useful intermediate view but makes the control state-dependent.

Clear and focus

After × erases query text

Ranking: C-keep > C-focus. C-keep changes only what Clear names; C-focus predicts the next action. Both keep the Search destination open.

Query on a new Search visit

After returning to player and reopening

Ranking: Q-new > Q-restore. Q-new matches a new player-to-Search task; Q-restore is quicker for the same task. This choice does not select the returning result position.

Results on a restored query

Only when Q-restore is chosen

Ranking: P-top > P-prior. P-top limits surprise on a new visit; P-prior favors continuity. With Q-new there are no results to restore, so this preference has no effect.

Same-query keyboard refocus

Scrolled row after the viewport shrinks

Ranking: S-visible > S-offset > S-top. Visibility without extra recovery is preferable to an observed extra swipe; preserving the nearby offset still retains more context than jumping to top. A changed query resets to top in this schematic only.
