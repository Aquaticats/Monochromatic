Companion reading loop

  1. Read one linked page of the experimental Rust Book.
  2. Hide the source page and answer the companion's retrieval prompts from memory.
  3. Commit to each answer before revealing feedback.
  4. Reopen the source page for anything the feedback did not resolve.
  5. Inspect the linked monorepo source only when the lesson says the required concepts are available.
  6. Ask the teaching agent about anything unclear.
  7. Return later and attempt the prompts again without rereading first.

This loop makes the Rust Book the teacher and the companion the practice and transfer layer.
