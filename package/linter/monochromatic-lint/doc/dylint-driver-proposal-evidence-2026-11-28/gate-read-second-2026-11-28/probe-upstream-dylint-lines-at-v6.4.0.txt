## README.md lines 201-223
   201	### Caching in CI
   202	
   203	If you run Dylint in CI, we recommend caching certain directories to avoid rebuilding libraries, rebuilding drivers, or redownloading toolchains.
   204	
   205	Current [Rust - Cargo guidance] recommends caching these directories:
   206	
   207	```yaml
   208	~/.cargo/bin/
   209	~/.cargo/registry/index/
   210	~/.cargo/registry/cache/
   211	~/.cargo/git/db/
   212	target/
   213	```
   214	
   215	In addition, we recommend caching these directories:
   216	
   217	```yaml
   218	~/.cargo/git/checkouts/
   219	~/.dylint_drivers/
   220	~/.rustup/toolchains/
   221	```
   222	
   223	Also, if you do not cache `target/`, we recommend at least caching `target/dylint/libraries/`.
